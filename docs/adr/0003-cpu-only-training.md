# ADR-0003 · CPU 전용 학습과 프로세스 병렬

- 상태: 채택

## 맥락
빌드 환경은 4코어 CPU, GPU 없음. 모델은 7,563 파라미터로 장면 1개 forward+backward 가 2.4 ms 다. 병목은 연산이 아니라
파이썬 루프·데이터 준비다.

## 결정
- 공식 데이터 준비(장면당 파이썬 이중 루프 + networkx, ETH 학습 분할 211 s) 를 numpy 브로드캐스트로 바꿔 1 s 미만으로 만들고,
  결과가 비트 단위로 같음을 검증했다.
- 학습은 분할별 프로세스를 `torch.set_num_threads(1)` 로 돌려 3~4개를 동시에 실행한다(스레드 병렬보다 효율적: 텐서가 작아 스레드 오버헤드가 크다).
- 250 epoch 공식 설정을 그대로 쓴다(분할당 30~50분).

## 결과
GPU 없이도 논문 설정 그대로 5개 분할을 두 시간 안에 재현할 수 있다. `results/logs/` 에 각 실행 로그를 남긴다.
