# ADR-0005 · 실제 RTLS 데이터 대신 합성 스트림

- 상태: 채택

## 맥락
공개된 공장 UWB RTLS 궤적 데이터는 없다(있어도 안전 사고 라벨은 없다). 회사 제품 데이터에는 접근할 수 없다.

## 결정
공장 레이아웃·작업자/지게차 이동 모델·UWB 노이즈(σ 0.15 m, 이상치, 드롭아웃)·near-miss 주입을 갖춘 합성 생성기를 만들고,
(1) 대규모 처리(수천만 행, 10 Hz → 2.5 Hz 리샘플, 장면 윈도우) (2) ETH/UCY 학습 모델의 전이·미세조정 (3) 충돌 위험 경보의
정밀도/재현율/선행시간 평가에 쓴다. 합성 데이터임을 README 첫 화면과 데이터 카드에 명시한다.

## 결과
"실제 안전 성능"을 주장하지 않는다. 주장하는 것은 파이프라인이 실데이터 규모와 형태를 감당한다는 것, 그리고 평가 프로토콜이 준비돼 있다는 것이다.
